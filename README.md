# 🏛️ Haryana Handloom Camp - Premium Home Furnishing Website

Luxury web application built for **Haryana Handloom Camp** in Nandyal, featuring their complete catalog of Bed Sheets, Cushion Covers, Curtains, Comforters, Mink Blankets, Polar Fleeces, Shawls, and Pillows with interactive WhatsApp inquiry ordering and custom room styling visualizer.

![Haryana Handloom Camp Header](https://images.unsplash.com/photo-1616486338812-3dadae4b4ace?auto=format&fit=crop&w=1200&q=80)

---

## ✨ Features

- 🌟 **Royal Deep Navy & Gold Aesthetic**: Styled directly based on the Haryana Handloom Camp store poster.
- 🛏️ **Interactive Product Catalog**:
  - Bed Sheets (Single, Double, King)
  - Cushion Covers (Embroidered Velvet & Boho Jute)
  - Curtains (Blackout Jacquard & Sheer Linen)
  - Comforters (Microfiber & Mink Blankets)
  - Blankets & Polar Fleeces
  - Shawls & Pillows
- 🎨 **Virtual Room Visualizer**: Allows customers to test bedsheets, cushions, and curtains in a room setup and share their custom look directly on WhatsApp.
- 🛍️ **Instant WhatsApp Inquiry Cart**: Select items and send a pre-formatted message straight to store representatives (+91 9215211025 / 9215511025).
- 📍 **Store Location & Contact Section**: Google Maps integration, store timings, landmark instructions (Near Sai Baba Mandir, NK Road, Nandyal - 518501).

---

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: Vanilla CSS3 + Custom CSS Tokens (Glassmorphism, Luxury Gold Gradients)
- **Icons**: Lucide React
- **Deployment**: Vercel

---

## 🚀 Local Development Setup

```bash
# 1. Clone repository
git clone https://github.com/tamanpreet5454/haryana-handloom-camp.git

# 2. Navigate to project directory
cd haryana-handloom-camp

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```
